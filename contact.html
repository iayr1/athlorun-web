My steps are not counting

Make sure Athlorun has the Physical activity permission and, if you use it, Health Connect access. Disable battery optimisation for Athlorun in Android Settings → Apps → Athlorun → Battery so it can count in the background.

GPS route looks wrong

Allow Precise location, wait for a GPS lock before starting a workout, and avoid starting indoors. Tall buildings and tunnels can reduce accuracy.

I forgot my password

On the sign-in screen, tap Forgot password and we'll email you a reset link. If you signed up with Google, use "Continue with Google" instead.
